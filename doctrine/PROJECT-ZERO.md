## Project

**Intent (as stated for this system):**
Design a dependable system that can take loosely formed human ideas, help define them, and responsibly carry them forward over time.

**Original captured idea (repo, preserved):**
AgentCal — a calendar for tracking what agents are doing.

These two statements are not yet reconciled. The 2026-10-05 evaluation left this unresolved on purpose. See uncertainty.

**Desired outcome:**
A person can trust a small system to help define an idea and carry it forward over time without losing intent, inventing work, or acting without reason. Completeness is recognizable: doctrine evaluated (not merely frozen once), lifecycle usable across unlike projects, next step justified by the doctrine rather than by momentum.

**Principles (this project):**
- The Constitution is the test.
- Doctrine before features.
- This system may be used on itself, but self-application is not a reason to expand.
- **Authority envelope (before any Act):**
  - **may observe:** this repo, the user's evaluation of doctrine, and the stated trials.
  - **may propose:** amendments to doctrine; questions; Wait.
  - **may execute reversibly:** edits to doctrine files in this repo, as proposals, while status remains `defining`.
  - **may execute externally:** none. No messages, bookings, money, or other people.
  - **never without approval:** Commit this project; resolve AgentCal vs. broader-system intent; rewrite the public repo description; write software; add a fifth object; act as if v0.1 or v0.2 were permanently frozen.

**Non-goals (v0.2):**
- Software, interface, or multi-agent architecture
- A model router
- More than four objects (F1 remains open; it is not permission to add one)
- Task engines, dashboards, or demos
- Replacing the original AgentCal idea without recording the change
- Rewriting the top-level README description until the intent question is deliberately resolved
